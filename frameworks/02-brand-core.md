# Plantilla — Bloque 2: Plataforma Estratégica de Marca (Brand Core)

## 2.1 Golden Circle (Sinek)

| Nivel | Definición | Prueba de validez |
|---|---|---|
| **WHY** — Propósito | | ¿Seguiría siendo cierto si la marca cambiara de producto? Si no, es un What disfrazado. |
| **HOW** — Diferenciador operativo | | ¿Un competidor puede copiarlo en 6 meses? Si sí, no es un How. |
| **WHAT** — Oferta tangible | | ¿Se puede comprar hoy? |

## 2.2 Valores por comportamiento observable

Un valor que no se puede incumplir no es un valor. Formato obligatorio:

| Valor | Comportamiento observable | Qué sacrificamos por sostenerlo |
|---|---|---|
| | Hacemos X incluso cuando… | |

**Test de eliminación:** si el opuesto del valor es absurdo ("valoramos la
deshonestidad"), el valor no diferencia y se descarta.

## 2.4 Estructura "The Only" (Neumeier)

> **El único** `[categoría]` **que** `[diferenciador]` **para** `[audiencia]`
> **en** `[contexto/geografía]`.

Validación en cuatro golpes:

| Test | Pregunta | ✓/✗ |
|---|---|---|
| Verdad | ¿Es literalmente cierto hoy? | |
| Unicidad | ¿Algún competidor puede decir lo mismo sin mentir? | |
| Relevancia | ¿Al usuario le importa lo suficiente para pagar o cambiarse? | |
| Sostenibilidad | ¿La operación lo aguanta a escala? | |

Si falla "Verdad", hay dos caminos: cambiar el claim o cambiar el producto. No
existe un tercero.

## 2.6 Prisma de Kapferer

| Faceta | Definición | Manifestación concreta |
|---|---|---|
| **Físico** | Atributos tangibles y códigos visuales | |
| **Personalidad** | Cómo habla y se comporta | |
| **Relación** | Tipo de vínculo con el usuario | |
| **Cultura** | Sistema de valores de origen | |
| **Reflejo** | Cómo el usuario cree que lo ven los demás al usarla | |
| **Autoimagen** | Cómo el usuario se ve a sí mismo al usarla | |

Reflejo ≠ Autoimagen. El primero es social y externo; el segundo es íntimo. Las
marcas con pricing power alto suelen ganar en Autoimagen.

## 2.7 Arquitectura de Marca

| Modelo | Cuándo aplica | Costo de marketing | Riesgo de contagio reputacional |
|---|---|---|---|
| Branded House | Una promesa, múltiples productos | Bajo | Alto |
| House of Brands | Audiencias o valores incompatibles | Alto | Bajo |
| Endorsed | La submarca necesita credibilidad prestada | Medio | Medio |
| Hybrid | Portafolio en transición | Medio-alto | Variable |
